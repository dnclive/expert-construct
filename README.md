# ООО «ЭКСПЕРТ» — сайт о кровельных работах

Одностраничный статический сайт компании ООО «ЭКСПЕРТ» (ремонт и монтаж кровли, металлоконструкции, навесы).
Без сборки, без форм, без скриптов, без аналитики и cookies.

## Файлы

- `index.html` — вся страница; стили встроены в `<style>`.
- `404.html` — страница «не найдено».
- `favicon.svg`, `favicon-32.png` — значок сайта.
- `og.png` — картинка для превью ссылок (1200×630), снята со `source/og.html`.
- `robots.txt`, `sitemap.xml` — для поисковиков.
- `CNAME.todo` — что сделать, когда будет назван домен (затем появится файл `CNAME`).

## Как править

Тексты, объекты и контакты меняются прямо в `index.html` любым редактором; проверить — открыть файл в браузере.
Если меняется заголовок или цифры — обновить `source/og.html` и пересобрать `og.png` снимком 1200×630.

## Публикация (GitHub Pages)

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Каждый push в `main`
публикуется сам, через минуту-две. Свой домен — файл `CNAME` с именем домена и DNS-запись CNAME на
`<владелец>.github.io` (или A-записи GitHub Pages для корня домена); затем включить «Enforce HTTPS».

## Фото объектов

Сейчас в блоке «Объекты» — заглушки. Фото положить в `img/` (JPEG/WebP, ширина ~1200 px) и заменить в
`index.html` блок `<div class="ph" …>…</div>` нужного объекта на
`<img src="img/<файл>" alt="<вид работ>, <место>" width="1200" height="900" loading="lazy">`.
