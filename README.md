# ООО «ЭКСПЕРТ» — сайт о кровельных работах

Одностраничный статический сайт компании ООО «ЭКСПЕРТ» (ремонт и монтаж кровли, металлоконструкции, навесы).
Без сборки, без форм, без скриптов, без аналитики и cookies.

## Файлы

- `index.html` — вся страница; стили встроены в `<style>`.
- `404.html` — страница «не найдено».
- `favicon.svg`, `favicon-32.png` — значок сайта.
- `img/` — фото объектов (см. ниже).
- `og.png` — картинка для превью ссылок (1200×630), снята со `source/og.html`.
- `robots.txt`, `sitemap.xml` — для поисковиков.
- `CNAME` — домен сайта для GitHub Pages: `construct.expertcom777.com`.

## Как править

Тексты, объекты и контакты меняются прямо в `index.html` любым редактором; проверить — открыть файл в браузере.
Если меняется заголовок или цифры — обновить `source/og.html` и пересобрать `og.png` снимком 1200×630.

## Публикация (GitHub Pages)

Адрес сайта: https://construct.expertcom777.com/

Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Каждый push в `main`
публикуется сам, через минуту-две. Домен задаёт файл `CNAME` (одна строка: `construct.expertcom777.com`); в DNS — запись CNAME
`construct` на `<владелец>.github.io`, без проксирования. В Settings → Pages включена «Enforce HTTPS».

Сайт живёт в корне домена: ссылки в `index.html` относительные, в `404.html` — от корня (`/`), чтобы
страница «не найдено» работала на любом пути. По адресу `<владелец>.github.io/<репозиторий>/` Pages
перенаправляет на домен.

Если домен сменится — поменять его в `CNAME`, `index.html` (canonical, og:url, og:image), `robots.txt`,
`sitemap.xml` и в этом файле.

## Фото объектов

Фото лежат в `img/`: на каждый объект — 600 px и полный размер (1200 px, у портретного снимка склада — 960 px,
кадрировано в 4:3), каждый в WebP и JPEG, качество 78. Страница отдаёт WebP, JPEG — запасной вариант для старых
браузеров; размер выбирает сам браузер (`srcset`/`sizes`).

Перед публикацией у фото удалены все метаданные (EXIF, GPS, модель камеры): снимки перекодированы заново, а
номер автокрана (Гривенская) и надписи на дальнем здании (Староминская) размыты. Новое фото готовить так же:
кадр 4:3, ширина 1200 и 600 px, без метаданных, без читаемых номеров машин, лиц и вывесок заказчика. Затем
в `index.html` поменять пути в `<picture>` нужного объекта и описание в `alt`.
